## Proyectos Destacados

### Kurve — Sistema de Control de Marketing

Plataforma de gestión y facturación por paquetes de horas para una agencia de marketing. **Lideré el proyecto de punta a punta**: definición de alcance por fases, coordinación del equipo de front y back, y nexo directo con el cliente.

**Stack:** `Next.js` · `TypeScript` · `Supabase (PostgreSQL, Auth, RLS)` · `Tailwind` · `Vercel` · `Resend`

- Diseño del modelo de datos relacional (M:N, enum de roles, vistas SQL de consumo) y **triggers de PostgreSQL** para el recálculo automático de horas en tiempo real.
- Lógica de **paquetes encadenados**: cierre automático al 100%, apertura del siguiente y traspaso de horas excedidas, resuelta en operaciones atómicas.
- **Endurecimiento de seguridad**: políticas RLS en 12 tablas, rate limiting y cierre de endpoints expuestos.
- Notificaciones por email transaccional con dominio propio verificado (DKIM / SPF / DMARC).
- Infraestructura de producción completa: subdominios, DNS en cPanel, CI/CD en Vercel, monitoreo de uptime, smoke testing E2E con datos reales y documentación para los 3 perfiles de usuario.

### Club Atlético Lanús — Sitio Web Institucional

API REST y panel de administración (CMS) para el sitio institucional del club.

**Stack:** `Node.js` · `TypeScript` · `Express` · `PostgreSQL` · `Sequelize` · `Next.js 15` · `React` · `JWT`

- CRUD completo del CMS desde cero: **7 entidades** (patrocinadores, jugadores, noticias, actividades, instalaciones, áreas, partidos) con relaciones M:N mediante tablas pivote y datos anidados, garantizados con **transacciones**.
- **Soft delete reversible** en todas las entidades, con limpieza de tablas intermedias para evitar datos huérfanos.
- Autenticación **JWT integrada al SSO del club** con control de acceso por roles (permisos diferenciados editar vs. eliminar).
- Helpers reutilizables: generación de slugs, borrado de imágenes en Vercel Blob y **sistema de auditoría** (quién cambió qué y cuándo).
- Diagnóstico y resolución de un **bug crítico de autenticación** (loops de redirección por `trailingSlash`) que habilitó el panel para todo el equipo, más el flujo de login OAuth contra el sistema de identidad del club.

### FlowForge — Migración a Arquitectura Serverless

Migración de un sistema de reportes a una arquitectura serverless, con foco en escalabilidad y reducción de deuda técnica.

**Stack:** `Next.js 14` · `NestJS` · `TypeScript` · `PostgreSQL / Prisma` · `Docker` · `Vercel` · `GCP`

- Migración del almacenamiento local (`fs/promises`) a **Vercel Blob**, eliminando dependencias de servidor y simplificando la operación.
- Stack completo de **Docker Compose** (PostgreSQL + Prisma) con migraciones y seeders automatizados: entorno reproducible en menos de 5 minutos.
- Esquema con **11 modelos y 10 enums** en Prisma, modelando usuarios, organizaciones, transacciones e invoicing.
- Resolución de errores de **React Context en Server Components** (Next.js 14) aplicando correctamente la frontera `'use client'`, y gestión segura de variables de entorno para deploy en Vercel.
